## Introduction

Short for **Mozilla Developer Network Web Docs**, [**MDN**](https://developer.mozilla.org/en-US/) is your go-to resource for Javascript, CSS, and HTML documentation. You can think of MDN as an owner’s manual of sorts, something you’ll reference as needed. 

Throughout this course (and your career), you’ll recall a method that is applicable to a given situation, but you’ll want some sort of documentation to reference as a quick refresher. MDN is a perfect resource in that scenario. 

Note, other documentation you encounter is likely to have a similar format to MDN. Getting comfortable with documentation early in your journey as a developer will set you up for success.

## About MDN

MDN Web Docs began in 2005 as Mozilla’s replacement for Netscape’s developer documentation. MDN is structured much like Wikipedia, where volunteers can submit changes and share knowledge. 

MDN Web Docs are actively maintained by Mozilla and volunteers from the JavaScript community.

In 2017,  Microsoft and Google shut down their own documentation projects and transitioned to MDN Web Docs.

Today, MDN is widely regarded as the best resource for documentation about open web standards.

**Check out [this link](https://developer.mozilla.org/en-US/docs/MDN/At_ten/History_of_MDN) if you’d like to know more about the history of MDN.**
